# Add MATE migration fixtures

Статус: **заблокирован средой** (тикеты 01) · Раунд 14 · ТЗ 3.4, ADR-0015, Q44

## Why

`tests/fixtures/mate-dconf/` пуст (`.gitkeep`, снимок `ls tests/fixtures/mate-dconf`
22.11.2026), `scripts/fixtures/capture-mate-dump.sh` не написан. Это последний открытый пункт
майлстоуна М0 после закрытия smoke (тикет 03, 22.11): без дампов МATE «миграция работает»
в DoD — непроверяемая формальность (ТЗ 3.4), а М1 (`crates/<имя>/migrate/`) обязан писать
карты соответствия **только против фикстур**.

Отдельная причина завести change сейчас, а не в М1: канон требует настоящий дамп из настоящего
Ubuntu MATE (ТЗ 3.4 + ADR-0015 «фикстуры — не из образа ворот»), а ADR-0006 запрещает писать
скрипт среды раньше прогона. Значит тикет открывается не кодом, а выбором машины-источника —
это решение владельца (Q98), и оно сегодня не принято.

## What Changes

- `scripts/fixtures/capture-mate-dump.sh` — пишется и **прогоняется в тот же день** (ADR-0006),
  только после того как среда-источник названа. Снимает: нетронутую установку и пользовательский
  сценарий (обои, тема, шрифты, привязки клавиш, раскладка панели), потому что `dconf` хранит
  только отклонения от умолчаний и «чистый» дамп сам по себе ничего не проверяет.
- `tests/fixtures/mate-dconf/*.dump` + рядом файл происхождения (id образа или машины, дата,
  версии пакетов MATE) — требование ТЗ 3.4, без него фикстура считается «почти зелёной».
- Никаких правок в ворота `xtask`: фикстуры — данные для тестов М1, отдельного шага ворот они
  не требуют, пока не появился первый потребитель (`izba/migrate`).

## Capabilities

### New Capabilities
- `migration-fixtures`: происхождение фикстуры, сценарии дампов, запрет рукописных дампов.

### Modified Capabilities
- (нет) — `gate-environment` не меняется: ADR-0015 уже вынес фикстуры из образа ворот.

## Impact

`scripts/fixtures/` (новый каталог), `tests/fixtures/mate-dconf/` (дампы + происхождение),
`docs/journal.md` (вывод прогона), тикет 01, CHANGELOG раунда. Код крейтов — ни одной строки:
карты `migrate/` относятся к М1 и без фикстур не пишутся.
