# Gate owner decisions

## Why

Три решения среды ворот принадлежат владельцу, а не агенту, и сейчас они — последние
открытые хвосты тикетов 00–01 (раунд 13, Q94/Q95):

1. **Порог `≥ 60 ГиБ` в `xtask ci --doctor`.** Красное «по месту» мерит `df` каталога
   проекта: при монтировании рабочего дерева с хоста мерится хост, а не среда ворот.
   Понизить меру — значит починить красные ворота правкой меры; запрещено без решения
   владельца.
2. **Запас места на томе хоста.** `Docker.raw` растёт по требованию; том умирал от
   99% (20.11). Требование запаса — политика владельца, не кодовая.
3. **Базовый образ amd64.** Пин digest'ом снят для arm64; amd64-замер не снят (место).
   Решение: собрать amd64-базу и записать второй digest, или объявить amd64
   экспериментальным до M5.

## What Changes

- Решение по каждому пункту — запись в реестр журнала (продолжение Q94) и ADR при сговоре;
  агент оформляет вариант, владелец утверждает.
- По решению 1: `doctor` мерит порог там, где его поставили (среда или хост — по выбору),
  подсказка указывает выбранную базу.
- По решению 3: `IMAGE-MANIFEST.md` получает строку amd64 с digest или явную пометку
  «экспериментально».
- Запас места: правило чистки (`docker system prune` порог) фиксируется в
  `docs/env-checklist.md`, кода не касается.

### Modified Capabilities
- `gate-environment`: «doctor говорит, чего именно не хватает» (база измерения порога —
  подтверждена владельцем), «Среда описана в репозитории» (digest подтверждён для каждой
  заявленной архитектуры).

## Impact

`xtask/src/main.rs` (`doctor`), `IMAGE-MANIFEST.md`, `docs/env-checklist.md`,
`docs/journal.md` (реестр). Тикеты 00/01 закрываются окончательно. Никаких новых
зависимостей.
