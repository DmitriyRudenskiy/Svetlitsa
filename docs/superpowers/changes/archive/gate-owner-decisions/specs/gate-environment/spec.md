# gate-environment — delta

## MODIFIED Requirements

### Requirement: doctor говорит, чего именно не хватает

`xtask ci --doctor` SHALL различать состояния среды: отсутствие Elementary — подсказка со
ссылкой на скрипт сборки; присутствие — строка с найденной версией; место — порог по `df`
с базой измерения (каталог проекта или каталог среды), подтверждённой владельцем в реестре
журнала. Порог и его база не понижаются и не переезжают без такой записи: красные ворота
не чинятся правкой меры.

#### Scenario: Elementary в образе есть

- **WHEN** `xtask ci --doctor` запущен в образе с `/opt/svetlitsa-efl`
- **THEN** вывод содержит `elementary 1.29.0 найден по pkg-config`, а подсказка про отсутствие
  Elementary отсутствует

#### Scenario: Красное «по месту»

- **WHEN** свободного места меньше подтверждённого порога по подтверждённой базе
- **THEN** doctor красен по этой единственной причине и печатает базу измерения (хост/среда)
  вместе со ссылкой на решение владельца

### Requirement: Среда описана в репозитории, а не на чужой машине

Базовый образ SHALL пиниться digest'ом для каждой заявленной архитектуры (или архитектура
явно помечена экспериментальной), содержимое образа SHALL задаваться `Dockerfile` и
`scripts/dev-vm/efl-build.sh` — одними и теми же файлами для CI и для человека. Рабочее
дерево в образ не копируется: оно приезжает монтированием.

#### Scenario: Пересборка среды с нуля

- **WHEN** `docker build` выполнен на чистой машине из текущего коммита
- **THEN** полученный образ совпадает с задокументированным в `IMAGE-MANIFEST.md`
  (тег, image id, базовый digest соответствующей архитектуры), и ни один шаг ворот не
  требует ручных шагов между сборкой и прогоном
