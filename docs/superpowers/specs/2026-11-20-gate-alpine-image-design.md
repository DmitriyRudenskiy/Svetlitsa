# Среда ворот становится Docker-образом на Alpine (раунд 13)

**Дата:** 2026-11-20, правки 2026-11-21 · **Тикеты:** `.scratch/gate-alpine/issues/00…04` · **Реестр:** Q94–Q95 в `docs/journal.md`, ADR-0015 (уточняет ADR-0003)

> Спека коммитится после тикетов 01 и 02, а не до них, — и это её свойство, а не упущение:
> каждое число ниже снято прогоном, предсказаний в файле нет. Формулировки решений,
> исправленные по ходу раунда, вынесены в последний раздел и не переписывают таблицы выше.

## Проблема (что наблюдали, а не что хочется починить)

1. **М0 четвёртый раунд стоит «ожидает среду».** План Q40/Q44 («ворота на облачной
   QEMU/KVM-VM с гостем Ubuntu MATE») не исполнен ни разу; `xtask smoke` не запускался ни разу;
   `smoke_proven()` в `xtask/src/main.rs` — вручную зашитый `false`, и ни один лист парити не
   имеет права на `готово` (Q83).
2. **Среда хоста умерла, а не «не запущена».** 19.11.2026 в 07:08 Linux-ВМ Docker упала в
   `no space left on device` (лог `com.docker.virtualization.log`), том Data — 99% занято.
   При этом `docker --version` оставался зелёным: это версия **клиента**, демон он не проверяет.
3. **`xtask ci --doctor` краснел по пунктам, которые никто не мог назвать числом**: «Elementary
   1.29 не найден» и «свободно N ГиБ из требуемых 60» — а сколько весят сами компоненты среды,
   не знал никто, включая автора порога.

## Решения

| ID | Решение |
|---|---|
| Q94 | Среда ворот — Docker-образ на Alpine, **артефакт репозитория** (`Dockerfile` + `IMAGE-MANIFEST.md` с digest'ами), а не чужой компьютер. Заменяет Q40/Q44; `.86` остаётся фикстурами Ubuntu и `origin`, но воротой не становится |
| Q95 | musl — **единственная** среда сборки и прогонов; второго glibc-образа-ворота нет. Риск назван списком (NSS/резолвинг, `iconv` вне libc, упаковка в чужой glibc-среде), точка пересмотра — M5, где прогон установки в glibc-дистрибутиве вписан в майлстоун (тикет 04) |
| ADR-0003 | EFL 1.29.0 с Elementary — **один** pinned-тарбóл `efl-1.29.0.tar.xz` (отдельного тарбóла Elementary не существует), сборка meson+ninja в `/opt/svetlitsa-efl`, флаги — из `testing/efl/APKBUILD` с тремя отклонениями: `-Db_lto=false`, `-Dprefix`, `-Dpipewire=false` |
| 21.11 | `pipewire-dev` в образ **не ставим**: ворота звук не тестируют, v1 проекта живёт на PulseAudio-совместимом слое. Для M5-пакета (где звук и есть PipeWire) решение пересматривается — записано в тикете 04 и в комментарии скрипта, не в памяти. Новым Q не заводилось: адрес решения — ADR-0015 п. 3 |
| 21.11 | Порог doctor'а `≥ 60 ГиБ` **не понижен**: красные ворота не чинятся правкой меры. Величина для пересчёта получена (дерево EFL — 0.5 ГиБ, образ — 2.81 ГБ), но сам пересчёт — решение владельца |
| 21.11 | `target/` и cargo-зеркала — именованные volumes, а не bind-mount: не из статей, а из замера 1.4× (см. метрики). Отдельным правилом не становится — это режим запуска, а не свойство кода |

## Объём раунда

**Входит (тикет : что):**

1. 00 — диагноз среды: лог ВМ, `du` по тому, таблица «что весит»; шаги, которые выполняет
   только человек (освободить том, штатно перезапустить Docker Desktop). Блокер снят
   человеком 21.11, тикет открыт остатком: запас места + решение про 60 ГиБ.
2. 01 — `Dockerfile` на `alpine:3.24`, rustup по `rust-toolchain.toml` (пин в образе не
   дублируется), volumes, четыре метрики числом, прогон `cargo test --workspace` внутри.
3. 02 — `scripts/dev-vm/efl-build.sh`: пин + sha256 + флаги, запечён в образ тем же
   `COPY`/`RUN`, которым собирается; doctor проверяет `elementary` по pkg-config.
4. 03 — первый **ручной** smoke (`xvfb-run` + `xdotool` + снимок), только потом раннер,
   только после артефакта прогона `smoke_proven()` читает файл. Не начат.
5. Документы: `IMAGE-MANIFEST.md`, `docs/env-checklist.md`, ADR-0015 (новый), уточнение
   ADR-0003, ТЗ (термин «Среда ворот», 3.8, майлстоун M0/M5), глоссарий, CHANGELOG, журнал.

**Не входит (реестр «не исполнено», а не «сделано»):**

- Замер `--platform linux/amd64`: второй образ +2.8 ГБ, а на томе 7.2 ГиБ. Отложен
  capacity, а не вкусом; снимается по слову владельца или переездом на .86-подобную машину.
- Кэш тарбóла EFL в CI: сервер релизов однажды отдал файл на ~250 КБ/с; пока это строка
  манифеста, а не `buildkit cache`.
- glibc-проверка упаковки — только M5/тикет 04, «больше нигде вслух».
- `smoke_proven()`, `xtask smoke`, артефакты в `artifacts/` — тикет 03, до первого
  увиденного окна кода раннера не пишется (ADR-0006).

## Правки и уроки раунда (не переписывают решения выше)

1. **Проверка чтением не заменила прогон — ровно один раз, но в самом дорогом месте.**
   Флаги из `testing/efl/APKBUILD` «совпадали» до первой `meson setup`: EFL 1.29 по умолчанию
   требует `libpipewire-0.3 >= 1.4.0`, которого в makedepends 1.28.1 нет. Цена правила ТЗ 3.8
   «написать и прогнать в тот же день» — один упавший configure, а не неделя «почти зелёного»
   скрипта в репозитории.
2. **`docker --version` не является проверкой демона** — живой клиент при мёртвом демоне
   выглядит как исправный терминал. Живое подтверждение — `docker version`/`docker info`;
   причина простоя найдена в логе ВМ, а не перезапусками.
3. **Почти записан в факты вывод сломанной команды.** `cargo tree -e external` упал по флагу,
   `grep -c` по выводу дал «0 внешних зависимостей». Пересчёт `cargo tree --workspace`
   (41 пакет, все локальные) совпал по везению — но проверке не повезло бы. Фиксируем: вывод
   команды с ненулевым `exit code` фактом не считается.
4. **Два «на глаз» умерли замерами.** «Слой образа в десятки мегабайт» (ADR-0015, первая
   редакция) — тулчейн Rust весит 1.74 ГБ, втрое больше всей Alpine-базы с X11; «bind-mount
   тормозит в разы» — 1.4× на сегодняшнем дереве. Число из статьи — тоже не замер.
5. **`df` в doctor'е мерит не среду, а каталог проекта** — при монтировании с хоста это место
   владельца, и красные «9.2 ГиБ» сосуществуют с 948 ГиБ внутри. Это не чинится в коде раунда:
   порог остаётся, пересчёт — за владельцем.
6. **Docker.raw sparse, и свободное место хоста — динамическая величина раунда**: за день
   2.6 → 15 → 6.5 → 7.2 ГиБ (сборка с EFL съела). Отсюда честная формулировка блокировки
   amd64-замера: не «не хотим», а «не влезет».
7. **Убрано за раунд:** второй тарбóл Elementary (его нет), пакетные `rust*` в образе
   (второй `rustc` в PATH сбивает doctor), `cargo-audit`/`rust-bindgen` (потребителей нет),
   scratch-volume с EFL после запекания слоя, висячий до-EFL образ (`docker image prune`).

## Что остаётся после спеки

- **Тикет 03** — первый ручной smoke в этом образе; он ни людей, ни гигабайт не требует.
  Порядок зафиксирован в тикете: сначала увидеть окно, потом раннер, потом `smoke_proven()`.
- **Решения владельца:** судьба порога 60 ГиБ (величина для пересчёта есть); надобность
  amd64-замера (упрётся в диск или в машину .86); M5-пакет — тикет 04, там же пересмотр
  `pipewire=false`.
