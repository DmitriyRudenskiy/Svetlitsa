## Бытовое по этой машине

- `timeout` в macOS нет (`gtimeout` или фон+kill); `git worktree` без `git worktree prune` оставляет мусор;
  у `git worktree prune` нет флага `-q`.
- `root()` в xtask обязан звать `git_in(Path::new("."), …)`, а не `git()` — `OnceLock` на реentrant вход вешает поток.
- Подписывает теги `git tag -s` (ключ из `user.signingkey`); `git tag -u canon@svetlitsa` ставит **без подписи**,
  печатая успех. Проверка: `git cat-file tag X | grep -c 'BEGIN SSH SIGNATURE'`.
- Не откатывать мутацию `git checkout <файл>`, если в файле незакоммиченная работа (раунд 9 потерял так правку;
  спасли повторным патчем). Рабочий приём: `cp файл /tmp/…good`, мутация, прогон, `cp` обратно.
