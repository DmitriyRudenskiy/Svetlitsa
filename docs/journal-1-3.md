# ADR-0001. Имя проекта — «Светлица» (svetlitsa)

Статус: принято · Дата: 2026-11-14 · Затрагивает: брендинг, имена крейтов/бинарей/D-Bus (TASK.md §7)

## Контекст
Проект — порт рабочего стола MATE («мята») на Rust + EFL (Enlightenment — «просветление», свет).
Принята русская система имён с народным мотивом (§7.2); имя проекта должно объединить обоих
родителей и выдержать народный стиль остальных имён (изба, лавка, горница…).

## Варианты
| Вариант | За | Против |
|---|---|---|
| **Светлица** | свет — прямая отсылка к Enlightenment/EFL; мята — привет MATE (мяту сушили в светлицах, мятный настой — «mate»); светлая горница — точная метафора рабочего стола; рифмуется со всей системой имён | длинновато для D-Bus (`org.svetlitsa.*`) — приемлемо |
| Терем | множество окон и ярусов — образ WM | не держит связь с MATE; «архитектурно» |
| Лад | гармония и безопасность Rust — «жить в ладу» | абстрактно; сильнее как принцип, чем как имя |
| Сплав | слияние MATE + Enlightenment через Rust | безлично, технично |

## Решение
Имя — **«Светлица»** (латиница `svetlitsa`). Слоган проекта — «Всем светло», релизный —
«Мята и свет». «Лад» фиксируется как принцип проекта: память без гонок и паник — это
лад с пользователем и железом (TASK.md §7.1).

## Последствия
- Workspace — `svetlitsa/`; крейты — `svetlitsa-*` и народные имена §7.2; D-Bus — `org.svetlitsa.*`.
- Отклонённые варианты зафиксированы здесь и в §7.1; повторное обсуждение — только новый ADR.
- Смена имени портированного компонента — через ADR (§12.7).

# ADR-0007. Публикация крейтов и имена

Статус: принято (решение раунда 2026-11-15) · Затрагивает: TASK.md §3.9, §4.2

## Решение
- До 1.0 крейты не публикуются на crates.io — workspace-внутренние (`publish = false`
  уже в манифестах).
- Бинари в дистрибутивах ставятся как `izba`, `lavka`, `traktir`, `vestnik`, …
  (короткие имена §7.2); коллизии с существующими пакетами дистрибутивов — проверить
  при упаковке М5.
- D-Bus — `org.svetlitsa.*`.
- Резервирование имён `izba`/`lavka`/… на crates.io — отдельное решение перед 1.0;
  в 1.x — не делать без ADR.

## Последствия
- Имена крейтов остаются короткими и «человеческими» без префиксов-неймспейсов;
  риск коллизий на crates.io не влияет на внутреннюю структуру до 1.0.
