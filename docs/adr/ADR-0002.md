# ADR-0002: Лицензии — наследуем сверху вниз по upstream, публикуем CSV

Дата: 2026-11-15 · Статус: принято · Решение раундов 1–2 (Q7, Q17)

## Контекст
В первой редакции ТЗ лицензий не было вообще. Порты — производные работы GPL-кода MATE, поэтому
«MIT/Apache-2.0 на весь проект» юридически невозможен. Проверено по зеркалам: большинство — GPL-2.0+,
`mate-terminal` и `mate-netbook` — GPL-3.0+, `mozo` и `libmateweather` — LGPL-2.1+, а
`libmate-desktop`, `mate-menus`, `libcaja-extension` — **LGPL-2.0+** (в upstream есть `COPYING.LIB`),
то есть ядра `izba`/`traktir`/`ambar-core` нельзя лицензировать как GPL. `caja` — микс GPL-2 + LGPL-2 +
`COPYING.EXTENSIONS`.

## Решение
- Порты приложений — GPL-2.0-or-later; `morzyanka`, `lezanka` — GPL-3.0-or-later; `bufetchik`, `vedro` —
  LGPL-2.1-or-later; `izba`, `traktir`, `ambar-core` — LGPL-2.0-or-later; инфраструктурные крейты
  (`svetlitsa-*`, `xtask`) — MIT OR Apache-2.0.
- Механика: `xtask licenses` генерирует `docs/licenses.csv` из `vendor/mate/*` (COPYING + заголовки
  исходников) на машине с зеркалами; CSV коммитится. В воротах `xtask ci` проверяется сам CSV: он есть,
  схема читается, каждый крейт workspace упомянут, лицензия совместима с зависимостями (cargo-deny).
- Профиль cargo-deny (список допустимых лицензий зависимостей) финализируется на М0.

## Последствия
- Зеркала (`vendor/mate/`) нужны не только для чтения кода, но и как источник юридически значимых
  файлов → они на машине с дисковым бюджетом, а не там, где их физически нет.
- Формулировка «-or-later» опирается на заголовки исходников, а не только на COPYING.
- **Проверено по зеркалам 15.11.2026** (`scripts/fetch-vendor.sh`, 43 репозитория): `mate-terminal` и
  `mate-netbook` — COPYING «Version 3»; `mozo` и `libmateweather` — «GNU LESSER … Version 2.1»;
  `mate-desktop`, `mate-menus`, `mate-panel`, `mate-screensaver`, `mate-settings-daemon` — GPL-2 (COPYING)
  **плюс** LGPL-2.0 (COPYING.LIB) на библиотечные части; `caja-extensions` — чистый GPL-2;
  заголовки `caja/libcaja-extension/*` — «GNU Library General Public License … version 2 or later», то
  есть LGPL-2.0-or-later, как и решено.
- Следствие для лавки: `mate-panel/libmate-panel-applet` — **LGPL-2.0** (COPYING.LIB), поэтому внешний
  интерфейс апплетов v2 нельзя лицензировать как GPL-часть лавки (ТЗ 9.7).
- Минус: CSV — производный артефакт, он устаревает при смене зеркал; проверка ворот ловит только
  отсутствие/схему, а не расхождение с upstream.
