# ADR-0024: Темой по умолчанию становится «Чикаго» (язык Windows 95); «Лубок» — выбираемая альтернатива

**Дата:** 22.11.2026 · **Статус:** принято (решение владельца 22.11.2026: «тема чикаго становится
каноничной») · **Вопрос:** Q100
**Пересматривает:** ADR-0012 (в части «названия палитр из ТЗ 7.3 неизменны»), ТЗ 7.1 (эстетика),
ТЗ 7.3, ТЗ 10.3 (провалка «серой темы»), GLOSSARY (статьи о палитрах), `docs/roadmap.md`
**Основание:** openspec-change `chicago95-primary-theme`

## Контекст

Контракт фиксировал обратное: «Лубок» — единственная визуальная система, народная, а «серая тема по
умолчанию считается браком» (ТЗ 7.3, 10.3, ADR-0012). До этого ADR в дереве лежал пропозал, который
этому контракту противоречил: 15 строк `TASK.md` со словом «Лубок», две статьи `GLOSSARY.md`,
строка `docs/roadmap.md` и строка ADR-0012 про неизменность имён палитр. То есть направление
нельзя было ни реализовать, ни отклонить, не сломав ворота 10.3 — сначала нужен документ.

Что проверено (команды рядом с числом):

- **`license: None` у `grassmunk/chicago95`** — `curl -s https://api.github.com/repos/grassmunk/chicago95`
  22.11.2026 вернул `license: None`, `stargazers_count: 6024`, `pushed_at: 2026-10-01`. Без лицензии
  действует «все права защищены»: копировать CSS/PNG/звуки/шрифты/иконки нельзя, `xtask licenses`
  обязан ловить такую попытку.
- **Ассеты Microsoft — отдельный риск, а не тот же самый.** Шрифт MS Sans Serif, звуки Windows 95,
  логотипы и набор `Icons/` воспроизводят проприетарные продукты; плюс trade dress — сходство
  внешнего вида само по себе может быть предметом претензии. Это риск публикации, а не сборки,
  поэтому он решается владельцем, а не техникой (см. решение 3).
- **`themes/` в дереве пуст** — темы как кода нет, менять нечего; вопрос стоит «какой быть первой
  теме», а не «что делать с готовой».

## Решение

1. **Тема по умолчанию — «Чикаго»**: язык Windows 95 (фаски raised/sunken 2 px, лицо `#C0C0C0`,
   заголовок `#000080`→`#1080B0`, обои `#008080`), реализованный **EDC-макетом Elementary**, а не
   файлами чужого репозитория. Семейство: «Чикаго» (светлая), «Графит» (тёмная, та же геометрия),
   «Мезень» (контрастная, доступность — без изменений против текущего контракта).
2. **«Лубок» («Гжель», «Хохлома») и декор «Наличники» остаются** выбираемыми альтернативами.
   Смена направления не удаляет народную линию и не объявляет её браком: она меняёт только то,
   что включено, когда настройки нет.
3. **Из чужого репозитория не переносится ни один файл.** Переносится визуальный язык — геометрия,
   пропорции, цвета (цвета и геометрия объектом авторского права не являются). Шрифтовая пара
   PT Sans/PT Serif и звуковая тема «Колокольчики» не меняются: звуки Win95 и MS Sans Serif не
   переносимы ни в каком виде. Запрет источников (`grassmunk/Chicago95`, ассеты MS) живёт
   запрет-листом в `xtask licenses` (задача 2.2 change'а).
4. **Степень сходства принимает владелец.** Владелец принял воспроизводство геометрии и палитры
   при собственном производстве всех ассетов (22.11.2026). Риск trade dress на этом не закрывается:
   он перечисляется ещё раз перед публичным релизом «Ярмарка», потому что цена претензии — снятие
   релиза, а не правка файла.
5. **Ворота 10.3 переписаны**: критерий «серая тема — брак» становится «UI обязан совпадать
   с токенами выбранной темы». `#C0C0C0`, пришедший из токена «Чикаго», — законное значение;
   голый Elementary без темы остаётся красным; правило «не менее 10 различных цветов» в силе.
6. **ADR-0012 отменяется в части «названия палитр из ТЗ 7.3 неизменны»** — иначе новое имя темы
   по умолчанию нельзя произнести. Остальная его часть (закрытые списки виджетов и иконок,
   запрет второй системы имён) сохраняется и распространяется на «Чикаго» в первую очередь:
   имена иконок по-прежнему freedesktop, закрытый список живёт в `docs/parity/svetlitsa-ui.md`.
7. **Имена и маска не меняются.** Русская система имён компонентов (ТЗ 7.2), D-Bus-адреса,
   конфиг-ключи, маскот «Конёк» — вне решения. Меняется слой «как выглядит», а не «как называется»;
   новый слой имени палитр («Чикаго»/«Графит») остаётся в той же русской системе имён.

## Альтернативы

- **Оставить «Лубок» темой по умолчанию.** Отклонено владельцем 22.11.2026.
- **Вендорить тему Chicago95.** Отклонено: у репозитория нет лицензии, ассеты воспроизводят
  продукты Microsoft. Дешевле нарисовать фаску самому, чем снять релиз.
- **«Чикаго» как одна из тем, но не по умолчанию.** Отклонено: направление — это и есть тема
  по умолчанию; альтернативой без статуса по умолчанию она уже была бы «Гжель».

## Последствия

- Ни одной строки в `themes/chicago/` до этого ADR (требование спеки «смена направления зафиксирована
  в каноне»). ADR есть — задачи 2.x–5.x change'а можно открывать, начиная с `tokens.toml`.
- Правки контракта сделаны этим же коммитом: ТЗ 7.1, 7.3, 10.3, таблица артов, GLOSSARY, roadmap.
- М1 (`m1-toolkit-foundation`) при применении берёт тему по умолчанию из нового контракта;
  М2 (`m2-session-frame`) выбирает декор по теме, по умолчанию — Win95-вариант.
- Цена: народная линия не исчезает, но перестаёт быть тестовым полигоном — эталоны SSIM и скриншоты
  быстрых контуров будут перетерты под «Чикаго» один раз после заморозки токенов (ТЗ 1016).

## Открыто (за владельцем, ADR это не решает)

- **Курсоры:** свой Win95-набор или системный `default` до М3 (задача 6.1 change'а).
- **Обои:** «Пейзажи» остаются народными или к ним добавляется бирюзовый «рабочий стол 95» (6.2).
