# ADR-0016: Отказ от X11 — Wayland единственная платформа, Xorg-сессии в 1.0 нет

Дата: 2026-11-21 · Статус: принято · Решение владельца (21.11.2026), ТЗ 3.6, 12.3, ADR-0002, ADR-0007

## Контекст

Контракт был X11-первым: портируем X11-механизмы MATE, а Wayland — «вторичный режим» (ТЗ 12.3),
в белом списке зависимостей висел `x11rb` (ТЗ 3.3), в ограничениях — «X11-сессия остаётся
поддерживаемой» (ТЗ 12.3). При этом в коде X11 нет: `grep -ril x11rb crates` пуст, `x11rb = "0.14"`
жил один в `Cargo.toml` как обещание.

Держать две платформы — это два прогона каждой проверки и два ответа на каждый вопрос «как это
работает». Для проекта, где 43 компонента ещё не написаны, это не запасной путь, а постоянный налог.

## Решение

**Wayland — единственная платформа «Светлицы».** X11-сессия, Xorg-компоненты и X11-специфичные
механизмы в 1.0 не входят. Что это значит по пунктам:

1. **X11-ссылки в ТЗ — история, а не требование.** Формулировки вида «реализовать XSettings через
   `xsettingsd`» описывают **механизм оригинала MATE**, а не объём копии. Право их менять есть только
   у задачи, которая их касается, — после этого ADR.
2. **Белый список ТЗ 3.3 очищается от X11.** `x11rb` из него уходит вместе с обоснованием
   («заменяется x11rb» в строке `libwnck` переформулируется: замена — layer-shell/seat, а не другой
   X11-клиент).
3. **Ворота не знают про X11.** `xtask ci --doctor` ищет композитор, а не `Xvfb`; `xtask smoke`
   поднимает сеанс под композитором; `scripts/efl-build.sh` собирает EFL с Wayland-бэкендом
   (`Ecore_Wl2`).
4. **Механизмы переезжают по таблице замен** (ТЗ 3.6): `XSettings` → `svetlitsa-config` +
   `portal:Settings`, `XEmbed`/`StatusNotifier` → `org.kde.StatusNotifierWatcher` поверх
   `zwlr-data-control`/слоёв, `EWMH` → layer-shell + `xdg-shell` + `ext-workspace`, `xkb`-через-X11 →
   `xkbcommon` + `keymap`/`keyboard-shortcuts-inhibit`, буфер → `zwlr-data-control`,
   `RandR`/`DPMS` → `wlr-output-management` + `ext-session-lock`.

## Последствия

- **Риск №1 переезжает с кода на бэкенд EFL.** Обязательная поверхность (ADR-0004) — Elementary,
  её Wayland-бэкенд `Ecore_Wl2` в 1.29 протестирован хуже X11-бэкенда. М0 обязан это измерить, а не
  узнать в М2: `xtask efl-build` + `xtask smoke` + скриншотный прогон.
- **Каждая проверка требует композитора.** Headless-сборка остаётся (`cargo build --workspace`),
  но «проверено» теперь означает «проверено под композитором», и CI-образ (ADR-0013) обязан его
  содержать.
- **Отказ от X11 не отменяет 43 репозитория MATE.** Меняется способ снять копию: не повторить
  механизм, а закрыть ту же заботу способом платформы (ADR-0018).
- **Обратного пути нет в пределах 1.x.** Вернуть X11-сессию — это новый эпик и новый ADR, а не
  флажок сборки.
