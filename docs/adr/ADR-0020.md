# ADR-0020: Внешние компоненты — вердикты по четырём репозиториям; менеджер буфера и секрет-агент

Дата: 2026-11-21 · Статус: принято · Разбор `idea/` (gxneur, parcellite, NetworkManager, conky), ТЗ 2, 9.x

## Контекст

В поле зрения проекта попали четыре внешних репозитория. Три из них — не MATE, то есть вне
канонического списка 43 репозиториев, по которому строится паритет. Нужно зафиксировать по каждому:
портируем, используем как образец, потребляем по протоколу — или не делаем ничего, — потому что
«интересный репозиторий» сам по себе не является основанием тянуть зависимость.

## Решение

| Репозиторий | Что это | Вердикт | Основание |
|---|---|---|---|
| **gxneur** | обёртка над X Neural Switcher, переключатель раскладки | **не портируем** | HEAD 2012-08-30, рабочее дерево 3 866 байта — spec, `sources` с md5 от tarball, пустой README; файла лицензии нет, `GPLv2` заявлено только в spec; функция делится между композитором (`keymap`, `keyboard-shortcuts-inhibit`) и «Букварём» |
| **parcellite** | менеджер буфера обмена, 7 300 строк C, GPL-3.0 | **модель → свой компонент «Памятка»** | Xlib + keybinder, переносить нечего; ценна модель: список настроек одной таблицей `myprefs[]`, лимиты истории, постоянный подсписок, фильтры мусора. Проект жив: версия 1.2.5 от 2024-07-10, HEAD 2025-12-16 |
| **NetworkManager** | сетевой демон, 665 000 строк, GPL-2.0+/LGPL-2.1+ | **потребляем по D-Bus** | демон в системе уже есть; пишем `zbus`-клиента (просмотр, подключение), а не редактор соединений и не свой демон |
| **conky** | оверлей-монитор, 51 495 строк C++ в `src/`, GPL-3.0 + историческая BSD-часть | **механика в образец, пост-MVP** | Wayland-сборка есть (`xdg-shell` + `wlr-layer-shell`), но выключена по умолчанию (`BUILD_WAYLAND` = false); как порт не нужен — `dozor`/`lavka` закрывают заботу слоями |

Два решения внутри строки NetworkManager:

1. **Секрет-агент — собственный клиент сеанса** (`org.freedesktop.NetworkManager.SecretAgent`),
   polkit-агент зависимостью не является: один интерфейс на `zbus` вместо ещё одного демона и чужой
   политики «кого спросить», плюс запрос секрета приходит в окне «Светлицы».
2. **Хранилище секретов — наша ответственность:** каталог сеанса (`0700`/`0600`), секреты не
   попадают в `svetlitsa-config`, в историю буфера и в журналы. Отказ от ввода — `CancelGetSecrets`
   и честная ошибка «не подключено».

## Последствия

- **В карте ТЗ 2 появляется поле вне MATE** — «Памятка» (`pamyatka`). Счётчик «43 репозитория MATE»
  не меняется, новые поля помечаются как «вне MATE», иначе паритет начнёт врать.
- **Ни один из четырёх не становится зависимостью.** Ни `libnm`, ни `libparcellite`, ни `libconky`
  в белый список ТЗ 3.3 не попадают; для NetworkManager достаточно D-Bus.
- **Половина ограничения ТЗ 12.15** («сеть — только через NetworkManager, своего демона не пишем»)
  снимается формально: мы его явно подтверждаем как потребление, а не как вынужденную меру.
- **gxneur без лицензии — полезный отрицательный результат:** он показывает, где кончается
  «интересно» и начинается «нечего брать, потому что брать нечего».
