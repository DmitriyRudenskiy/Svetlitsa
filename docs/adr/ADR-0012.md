# ADR-0012: Объём темы к М2 — закрытые списки виджетов и иконок, палитры не переименовывать

Дата: 2026-11-15 · Статус: принято · Решение раунда 4 (Q36), ТЗ 7.3

## Контекст
«Сделать тему» невыполнимо как критерий: иконок в `mate-icon-theme` тысячи, виджетов Elementary —
сотни. Плюс при обсуждении появилась соблазнительная ошибка — назвать палитры «Свет»/«Мрак», то есть
завести вторую систему имён поверх уже обещанной русской (ТЗ 6.6, 7.2).

## Решение
К М2 тема «Лубок» обязана покрывать: все Elementary-виджеты, которые к М2 используют лавка, ставни и
диалоги; обе базовые палитры — «Гжель» (светлая) и «Хохлома» (тёмная); декор «Наличники» для starshina.
«Мезень» (контраст, доступность) — после стабилизации двух базовых. Названия палитр из ТЗ 7.3
неизменны, новых систем имён нет.

Объём задаётся **закрытыми списками**: виджеты М2 и имена иконок живут в
`docs/parity/svetlitsa-ui.md`, пополняются явным изменением (PR), а не молча. `xtask icons` генерирует
список иконок из зеркала `mate-icon-theme` по freedesktop-именам, реально используемым М2-компонентами.

## Последствия
- Тема становится задачей с концом: закрытый список можно закрыть, «все иконки» — нет.
- Провалка «серой темы» в быстром контуре (ТЗ 10.3) опирается на те же токены, что и список.
- Минус: список надо не забывать пополнять; иначе приложение молча берёт иконку вне темы, и это
  перестаёт быть браком только потому, что никто не проверил.
