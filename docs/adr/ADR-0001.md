# ADR-0001: Монорепо с русскими именами крейтов вместо портирования по репозиторию

Дата: 2026-11-15 · Статус: принято · Решение раунда 1 (Q1)

## Контекст
ТЗ предписывает портировать 43 кодовых репозитория MATE на Rust + EFL. Каждый порт переиспользует
общую FFI-обвязку EFL, конфиги, D-Bus-слой и платформу. В модели «репозиторий на компонент» каждая
смена `svetlitsa-efl` порождает 28 PR в 28 репозиториях, а атомарные изменения через границу крейтов
невыполнимы.

## Решение
Один workspace (`crates/<имя>` на компонент, русские имена), версионируется вместе, релиз — общий тег.
Русская система имён (7.2 ТЗ) остаётся частью контракта: латиница в коде, русские названия в UI.

## Последствия
- Плюс: атомарные изменения через границу компонентов, один `xtask ci` на всё, общая смена API.
- Минус: имя крейта (`izba`, `traktir`, `lavka`) ничего не говорит внешнему человеку; карта
  «русское имя → C-оригинал» обязана жить в разделе 2 ТЗ и в README, иначе навигация невозможна.
- Минус: crate-имена `izba`, `traktir`, `lavka` на crates.io могут быть заняты — поэтому публикация
  отложена до 1.0 (ADR-0002, ТЗ 12.10), а workspace работает на путях без реестра.
