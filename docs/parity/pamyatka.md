## Вердикты (ручной блок — генератор его не трогает)
Статусы: `нет` / `в работе` / `готово` / `отложено (причина)`. `MVP` — обязательно к закрытию
компонента; «готово» для MVP-позиции означает зелёный smoke-сценарий (ТЗ 6.9), а не мнение
исполнителя.

| Позиция | Тип | Статус | Пометка |
|---|---|---|---|
| История записей буфера (текст) | MVP | нет | вызов по привязке композитора |
| Постоянный подсписок («закреплённые») | v1 | нет | переживает перезапуск |
| Вызов по глобальной привязке | MVP | нет | `X-механизм оригинала`: `XGrabKey`/keybinder → клавиатурные привязки `starshina` |
| Владение selection и отдача данных | MVP | нет | `X-механизм оригинала`: `XConvertSelection`/`XSelectionOwner` → `zwlr-data-control` (у MATE механизма-оригинала на Wayland нет) |
| Фильтры мусора и лимит истории (модель `parcellite`) | v1 | нет | переносится как модель, не как код: `parcellite` — GPL-3.0, Xlib (ТЗ 9.29) |
| «Не сохранять это» / приватный режим | MVP | нет | граница честности: если протокол не даёт пометки — запись в ТЗ 12.x |
| Синхронизация истории между машинами | отложено | отложено (приватные данные пользователя вне периметра 1.0) | — |

Причина: C-оригинала нет — в MATE менеджером буфера считался сам X11 (selection-владение),
историю держали сторонние утилиты; на Wayland буфер живёт у композитора, и без клиента
`zwlr-data-control` история невозможна (ADR-0021). Публичной поверхности переносить нечего.
Переносится: только модель поведения — перечень настроек, лимит истории и фильтры мусора по
образцу `parcellite` ([`analysis/externals/parcellite.md`](../analysis/externals/parcellite.md)),
собственный Rust API крейта `pamyatka`.
