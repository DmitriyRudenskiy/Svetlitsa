# Закрытый список имён иконок (`svetlitsa-icons`)

Инфраструктурный крейт: **имена** иконок и **исходы** их отыскания. Закрытый список имён М2
(ADR-0012), форма имени и четыре исхода отыскания — здесь. Пиксельный поиск остаётся за Efreet
(`svetlitsa-xdg`), поэтому слой имён живёт **до** EFL и обязан собираться без его заголовков
(ADR-0014). Появляется в **М2**, вместе с темой «Лубок».

## Что было в MATE

`libmateui` / `libmate-desktop` отдают имя иконки и просят GTK/Efreet найти файл: список имён
нигде не заперт, иконка ищется по `$XDG_DATA_DIRS` с наследованием hicolor, а отсутствие иконки
превращается в пустое место в UI без единого слова в журнал. Закрытого перечня нет — приложение
может попросить что угодно и молча получить ничего.

## Что сделано

- **Закрытый список — одна копия факта.** Парити-лист [`docs/parity/svetlitsa-ui.md`](../../docs/parity/svetlitsa-ui.md)
  встраивается (`include_str!`) и разбирается на лету. Генерируемого Rust-файла нет: третьей
  копии нет, поэтому расхождения «крейт говорит одно, лист — другое» не существует по построению.
- **Форма имени** — `^[a-z0-9]+(-[a-z0-9]+)*$`: kebab, строгий нижний регистр, без пустых
  сегментов, без подчёркиваний, нижней границы длины нет. Имя без дефиса (`home`) легально.
- **Повтор и калёное имя в листе — красный разбор списка**, а не молчаливое схлопывание в
  множество: `BTreeSet` сам по себе дубль прячет, и правило стало бы unverifiable.
- **Неразбираемый лист не роняет библиотеку**: список пуст, всякое имя — «чужое имя». Ловит это
  шаг `xtask icons --check` до коммита, а не `unwrap()` в проде (ТЗ 6.4).
- **Лога нет.** Предикат чистый; «строка в журнал» — контракт вызывающего кода.

## Что отложено

- Исходы отыскания (`Отклик` / `Промах` / `Чужое имя` / `Калёное имя`) и чистая функция
  «имя × тема → исход» — тикет 04 этого же раунда.
- Сам арт: 87 иконок «Лубка» в два слоя (ТЗ 7.3) — отдельная инициатива.
- Поиск файла, размеры, масштаб, кэш, наследование hicolor — Efreet / `svetlitsa-xdg` (ТЗ 3.4).
- Правка молчаливого пропуска в сверке парити-листов (шаг `parity` зеленеет без `vendor/mate`) —
  системный долг того же класса, раунд его не трогает.

## Доказательство, которого ещё нет

- **Сборка там, где EFL нет.** Названный прогон: `cargo build -p svetlitsa-icons --locked`
  на машине без заголовков EFL и без `pkg-config`. В среде ворот он **не исполнен**: самой среды
  ворот нет, а на этой машине EFL не стоит вовсе, то есть такая сборка прошла бы для любого
  крейта и ничего не доказала бы (Q57). Тест графа зависимостей — условие необходимое, но не
  достаточное: он не видит `pkg-config`, который приедет завтра вместе с новым `*-sys`.

## Правила

- Зависимостей нет вообще, `build.rs` нет. Это проверяет тест графа зависимостей в воротах
  (тикет 03), а не аккуратность автора: мутация «добавить `svetlitsa-efl`» обязана покраснить.
- Русского имени-прозвища у крейта нет: список 7.2 фиксирован и меняется только через ADR, а
  вторая система имён запрещена ТЗ 6.6.
- Лицензия — `MIT OR Apache-2.0` (ADR-0002): кода MATE здесь нет, есть только список имён.
