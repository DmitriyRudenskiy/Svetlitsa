# 01: Ворота `icons` сверяют список с зеркалом и краснеют без зеркала

**Parent:** `.scratch/svetlitsa-icons/spec.md`

**What to build:** Исполнитель запускает `cargo run -p xtask -- ci icons` и получает правду о
закрытом списке: сколько в нём имён, против какого отпечатка зеркала сверялось, и сошлось ли.
Список расходится с зеркалом в любую сторону — прогон красный и называет имя: **лишнее имя** (есть
в листе, зеркало его не знает) и **отсутствующее имя** (зеркало знает, в листе его нет) — это один
дифф в две стороны, а не два правила. Если зеркала `vendor/mate/` на машине нет — прогон **красный**
со строкой «зеркала нет — список не сверен», а не зелёное молчание, каким сегодня сворачивается
сверка парити-листов.

Это префакторинг генератора, а не новое правило об именах: генератор сегодня умеет только писать
лист, и его надо развернуть в три вещи — вывести список из зеркала, записать, сверить — по образцу
`parity` / `parity --check`, где режим сверки уже есть. Правил о форме имени и о повторах этот
тикет не вводит: их власть появится в 02, и переносить их дважды незачем.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Шаг `icons` входит в общий список шагов `xtask ci` и вызывается отдельно по имени шага
- [ ] Режим `--check` сверяет, не перегенерируя: после `--check` лист побайтно идентичен прежнему
- [ ] Прогон печатает дословно `icons: <N> имён · зеркало <sha> · список совпадает`; ни `87`, ни
      отпечаток не лежат в коде литералом; `N` снимает генератор, отпечаток — `mirror_head` (Q47)
- [ ] Отсутствие зеркала — красная строка «зеркала нет — список не сверен», ненулевой выход
- [ ] Лишнее имя в листе — красный прогон с этим именем; восстановлено — зелёный
- [ ] Отсутствующее имя (имя есть в зеркале, вырезано из листа) — красный прогон с этим именем
- [ ] Постоянный тест на временном каталоге без зеркала краснеет при возврате к молчаливому пропуску
- [ ] Три строки правил (лишнее имя, отсутствующее имя, молчание без зеркала) внесены в таблицу
      ТЗ 6.3 этим же тикетом, каждая со своей мутацией
- [ ] Каждая мутация реально прогнана, в журнале раунда — вывод `FAILED`, а не описание замысла (Q60)
- [ ] `cargo run -q -p xtask -- ci --local` зелёные
