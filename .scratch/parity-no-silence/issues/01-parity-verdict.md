# 01: Ворота `parity` не зеленеют, когда сверять нечего

**Parent:** `docs/handoff-round-10.md` (кандидат №1), правило — Q79, распространение Q67.

**What to build:** Исполнитель запускает `cargo run -p xtask -- parity --check` на дереве без
зеркала `vendor/mate/` и получает **красную** строку с причиной и выходом 1, а не зелёное
`parity: листов 0/31`. Причина сегодняшней зелени — `xtask/src/main.rs:1068`:
`let Some(head) = mirror_head(&row.repo) else { continue; }` с комментарием «вне зеркала — нечего
и сверять». Без зеркала ветвь срабатывает на каждой из 31 строки карты, `problems` остаётся
пустым, шаг печатает зелёный итог, не сверив ни одного листа. Раунд 10 показал этот контраст
красным по шагу `icons` (Q67) и назвал системный долг открытым.

Правило формулируется один раз и для всех шагов (Q79, ТЗ 6.3): шаг ворот не зеленеет, когда
сверять нечего. Три состояния красные — пустая карта, отсутствующее зеркало целиком, пропущенная
отдельно взятая строка карты; пропуск обязан быть назван именем репозитория, иначе он
неотличим от успеха.

Форма — та же, что у `icons` (тикеты 01–02 раунда 10): чистая `parity_verdict(&ParityState)`
судит правило, обход файлов собирает пропуски и кормит вердикт. Второй копии правила не
появляется: `parity` (генератор) краснеет без зеркала и раньше, красноту получает теперь сверка.

**Blocked by:** None (правила раунда 10 позволяют начать сразу).
