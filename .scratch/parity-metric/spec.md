# Spec: Метрика парити, которой можно верить (раунд 12)

Граница frontier была закрыта на grill (восемь решений, зарегистрированы Q82…Q89 —
`docs/journal.md`, раунд 12). Тикеты: `issues/01…05`.

**Проблема.** Ворота печатали `модулей .c: 1338 · вердиктами покрыто 0`: первое число —
позиции по листам, а не уникальные upstream-файлы (это разные числа: `uzelok` и
`uzelok-core` смотрят в один `engrampa`); второе — нулевое, потому что вердиктов нет.
Пока покрытие считалось подстрокой (`tail.contains(m)`, xtask/src/main.rs), а лист умел
«закрываться» по 100 % упоминаний, метрика не была основанием называть компонент
перенесённым. Плюс базовые имена не различают позиции: `main.c` в `skhodka` лежит в
четырёх каталогах, `gpm-common.c` в `kerosinka` — в четырёх.

## Solutions

- **Q85 — ключ позиции `каталог/файл`.** Генератор уже печатает столбец «Каталог», берём
  его. Базовое имя остаётся только в печатном списке для читаемости.
- **Q86 — вердикт = строка таблицы** с точным совпадением ключа и непустым статусом из
  легенды. Проза («Причина: …») и подстрока вердиктами не являются.
- **Q84 — модуль остаётся единицей счёта**, групповая строка покрывает ровно названные
  ключи; один ключ имеет ровно один вердикт, повтор с другим статусом красен.
- **Q82 — метрика печатает разные числа**: позиций и уникальных `каталог/файл`;
  покрытие дробью `покрыто N/M`, при M = 0 — «0/0 (нет позиций)» и красный цвет (Q79).
- **Q87 — функции считаются отдельно** своим парсером, своим ключом и своей дробью; в
  одно число с модулями не сливаются никогда; лист библиотеки не закрывается без `M/M`.
- **Q88 — `xtask parity --draft <крейт>`** только по явному флагу, идемпотентен, чужие
  статусы и прозу не трогает; пустой статус ≠ вердикт (Q47).
- **Q83 — до первого зелёного smoke-прогона статус `готово` запрещён** в легенде листа и
  в ТЗ 5; позиция бывает `нет` / `в работе` / `отложено (причина)`.
- **Q89 — штамп закрытия `Закрыт: <дата>, main@<sha>`**, ворота проверяют что объект
  существует и что он предок `main`; с `canon-rN` тег обязан существовать и указывать на
  этот sha.

## Построено (тикеты 01…05)

Построено тикетом 01:

- `xtask::position_keys` — перечень позиций, ключ `каталог/файл`, каталог `.` не печатается.
- `xtask::verdict_rows` / `xtask::status_ok` / `STATUS_LEGEND` — вердикт как строка таблицы.
- `xtask::sheet_problems` — считает позиции и покрытие по точным ключам, ловит конфликт
  статусов одного ключа; возвращает (проблемы, позиции, покрыто).
- `xtask::parity_verdict` — краснеет и без зеркала (Q79), и когда позиций нет вовсе.
- Строка ворот: `parity: листов 31/31 · позиций: 1338 · уникальных каталог/файл: 1233 ·
  покрыто 0/1338 · закрыто 0 · открыто 31` (команда `cargo run -q -p xtask -- ci --local`).

Ниже — что обязаны принести тикеты 02…05 (ещё не построено, записывать
в журнал по мере исполнения):
- `xtask::function_keys` — раздел «Функции»: ключ `каталог::имя`, свой парсер.
- `xtask parity --draft <крейт>` — скелет строк по незакрытым позициям, идемпотентный.
- `xtask::closure_problem` — штамп закрытия: объект, предок `main`, тег `canon-rN`.
- `docs/parity/traktir.md` — разбит М1-лист: шесть позиций с именами и пометками, без
  «Закрыт:».

## Commands

- `cargo run -q -p xtask -- ci --local` — ворота целиком (единственная зелёная команда
  этой машины, ТЗ 3.8).
- `cargo run -q -p xtask -- parity <крейт>` — проверить один лист.
- `cargo run -q -p xtask -- parity --draft <крейт>` — черновик вердиктов (Q88).
- `cargo test -p xtask` — 34 теста после тикета 01.

## Acceptance

- **Q85, Q86, Q84.** Позиция покрывается только точным ключом из строки таблицы;
  `menu.c` не покрывается вердиктом `window-menu.c`; проза не покрывает; групповая строка
  покрывает названные ключи; два статуса у одного ключа красные; тесты
  `подстрока_не_покрывает_позицию`, `проза_вердиктом_не_считается`,
  `групповой_вердикт_раскрывается_поимённо`, `конфликт_статусов_одного_ключа_красен`.
- **Q82.** Строка ворот печатает `позиций:` и `уникальных каталог/файл:` раздельно; ноль
  позиций красен (`ноль_позиций_красен_а_не_зеленый_ноль`).
- **Q87.** `функциями покрыто N/M` печатается рядом и независимо; `M/M` требуется для
  закрытия листа библиотеки; мутация «функции в общий счётчик» красная.
- **Q88.** Повторный `--draft` не удваивает строки; статус из черновика не подставляется;
  молчаливая правка блока красна.
- **Q89.** Мутации «sha нет», «sha не предок main», «canon-тег не на этом sha» красные.
- **Q83.** `готово` вне легенды; мутация, вернувшая его, красная.
- **Q53.** Каждый пункт красным до зелёного; в записи журнала — буквальный `FAILED`.
