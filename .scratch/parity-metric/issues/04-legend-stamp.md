# 04 · Легенда без «готово» и честный штамп закрытия

**Что делает система сегодня:** легенда листа позволяет `готово`, хотя зелёного
smoke-прогона (ТЗ 6.9) не существует ни для одной позиции; README показывает пример
`Закрыт: 2026-11-16, коммит порта \`abc1234\`` — ворота проверяют только то, что поле
непустое, и пример с фейковым sha прошёл бы.

**Goal:** статусное поле листа врёт меньше: `готово` запрещено до первого зелёного
прогона, штамп закрытия проверяется по git.

## Blocked by

01 · Метрика (легенда статусов уже разбирается).

## Milestones

- Легенда: `нет` / `в работе` / `отложено (причина)`; `готово` отсутствует — мутация
  «вернули в легенду» красная; та же правка в ТЗ 5 и в README.
- Формат штампа `Закрыт: <дата>, main@<sha>` (+ `canon-rN`, если закрытие совпало с тегом).
- Мутации красные: sha нет в дереве; sha есть, но не предок `main`; `canon-rN` не
  указывает на названный sha; в README больше нет строки, которую можно скопировать.
- Поле «Тип» таблицы остаётся (источник/замена/не переносится), статус им пользоваться не
  обязан — это отдельное поле от статуса готовности (решение grill, пункт 2).
