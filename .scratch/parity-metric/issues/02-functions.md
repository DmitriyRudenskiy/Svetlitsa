# 02 · Функции: отдельный парсер, отдельный ключ, отдельный счётчик

**Что делает система сегодня:** генератор печатает раздел «## Функции (142)» для восьми
библиотечных листов, но ни один парсер эти имена не считает — функция не является ни
позицией, ни чем-либо ещё.

**Goal:** `функциями покрыто N/M` печатается рядом с модульным счётчиком и независимо от
него.

## Blocked by

01 · Метрика — общий разбор листа и правила вердикта.

## Milestones

- `function_keys` — свой парсер раздела `## Функции`, ключ `каталог::имя` (функция
  принадлежит библиотеке листа, не каталогу `.c`).
- Строка ворот: `... покрыто N/P · функциями покрыто N/M ...`.
- Лист уровня «публичные функции» не закрывается без `M/M` — мутация «сняли требование»
  красная.
- Мутация «модули и функции в один счётчик» красная; мутация «обход парсера функций
  руками» красная; `0/0 (нет позиций)` для листа без раздела.

## Sign-off

Тикет закрывается коммитом с зелёными воротами и новой строкой; числа напечатаны.

**Решения:** Q87 (модуль остаётся единицей счёта — Q84; числа никогда не сливаются).
