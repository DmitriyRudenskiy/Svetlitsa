# 01 · Метрика: ключ `каталог/файл`, вердикт = строка таблицы, покрытие с знаменателем
**Статус:** закрыт (коммиты `feat 01` + `docs 01`, `xtask`: 34 теста, четыре мутации — журнал)

**Что делает система today:** покрытие считается подстрокой (`tail.contains(m)`), поэтому
`menu.c` считается покрытым вердиктом `window-menu.c`, а упоминание в прозе «Причина:»
даёт покрытию рост; строка ворот печатает `модулей .c: 1338`, хотя это позиции по листам,
а не уникальные файлы.

**Goal:** метрика, которой можно верить: позиция = `каталог/файл`, вердикт = строка
таблицы с точным ключом и непустым статусом из легенды, покрытие — дробью `N/M`.

## Blocked by

None — начинается с чистого дерева.

- `ключ_позиции_путь_а_не_имя`, `проза_вердиктом_не_считается`,
  `групповой_вердикт_раскрывается_поимённо`, `конфликт_статусов_одного_ключа_красен`,
  `статус_вне_легенды_красен`, `ноль_позиций_красен_а_не_зеленый_ноль`,
  `перечень_считает_модули_а_не_поверхность`.
- Строка ворот: `позиций: P · уникальных каталог/файл: U · покрыто N/P`.
- Мутации с буквальным `FAILED` в журнале: подстрока вместо точного совпадения,
  «покрывает любое упоминание», снятая проверка конфликта статусов, снятая ветка нуля
  позиций.
