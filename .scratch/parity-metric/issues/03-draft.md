# 03 · `xtask parity --draft <крейт>` — черновик строк вердикта
**Статус:** закрыт (коммит `feat 03`, `xtask`: 43 теста, четыре мутации — журнал)

**Что делает система сегодня:** `xtask parity <крейт>` перегенерирует блок и молчит;
человек получает перечень позиций и таблицу вердиктов без строк.

**Goal:** по явногому флагу — строки-скелет для незакрытых позиций; никогда молча.

## Blocked by

01 · Метрика (ключ `каталог/файл`, пустой статус ≠ вердикт).

## Milestones

- `--draft` печатает строки `| \`каталог/файл\` | модуль |  | подсказка: статус из легенды |`
  для позиций без вердикта; для библиотечного листа — и строки функций.
- Идемпотентен: повторный запуск не удваивает ключи; заполненный статус и прозу не трогает.
- Без флага поведение прежнее: ни одна строка рукописного блока не появляется — мутация
  «молча вставили блок» красная.
- Мутации «статус подставлен из черновика» и «ключ продублирован» красные (Q47).

## Sign-off

Тикет закрывается коммитом; два прогона `--draft` подряд дают тот же файл (diff пустой).

**Решения:** Q88.

**Итог.** Реализовано и проверено прогоном: `xtask parity --draft traktir` добавляет 148
строк (6 модулей + 142 функции), второй прогон — 0 строк и тот же файл, `parity --check`
печатает `черновиков: 148`, покрытие остаётся нулевым, `xtask ci --local` зелёный. Вёрстка
строки делегирует существующему `render_table`, занятость ключа — существующему `parse_rows`.
