## 1. Доводка сеанса (`novoselye`, 9.28, L)

- [ ] 1.1 Бинарь `novoselye`: порядок запуска (`starshina` → `klyuchnik` → `domovoy` → `vestnik` →
      `lavka` → автозапуск), обратный порядок остановки, переменные окружения сеанса
      (`WAYLAND_DISPLAY`, `XDG_CURRENT_DESKTOP=Svetlitsa`), отсутствие `DISPLAY`/`XAUTHORITY`.
- [ ] 1.2 Перезапуск после падения композитора: конечное время восстановления, стоп бесконечного
      цикла перезапусков, данные пользователя не трогаются (DoD 9.28).
- [ ] 1.3 `lavka` как layer-shell-клиент: слой панели, обои, десктоп-иконки `ambar-desktop` —
      порядок слоёв проверен снимком (спека `file-manager`).
- [ ] 1.4 Матрица прогонов «компонент × Ecore_Wl2»: все UI-компоненты и программы; ни одной строки
      со статусом «прошло» без фактического прогона.
- [ ] 1.5 **Правка контракта:** ТЗ 9.28 в абзаце «после ADR-0019» всё ещё называет собственный
      композитор на smithay «пост-1.0 эпиком, вне релиза „Ярмарка“ (ADR-0007)» — противоречие
      устранить тем же порядком, что и правки 3.19–3.20 `musl-only-libc` (решение принято ADR-0019,
      правка косметическая).

## 2. Бэкенд порталов freedesktop (4 интерфейса)

- [ ] 2.1 **ADR до первой строки:** (а) свой сервис `org.freedesktop.portal.Desktop` или
      (б) `xdg-desktop-portal` (в Alpine edge — `xdg-desktop-portal-1.22.1-r0`) + наш impl-бэкенд.
      В ADR — цена, риски расхождения со спекой порталов, что именно мы не получаем.
- [ ] 2.2 `FileChooser` — диалог на `svetlitsa-ui` поверх `svetlitsa-vfs`, отмена возвращается отменой.
- [ ] 2.3 `Screenshot` — тот же путь захвата, что у `dagerotip` и smoke (спека `screen-capture`),
      второго пути захвата не появляется.
- [ ] 2.4 `Settings` (тема/обои) — через `domovoy`/`izba` в `svetlitsa-config`, чтобы не появилось
      второе место правки той же настройки (правило 9.20).
- [ ] 2.5 `Notification` — поверх `vestnik`, включая приоритеты и do-not-disturb.
- [ ] 2.6 Проверка реальным сторонним клиентом (не собственным вызовом) + запись зависимости
      порталов в allowlist и манифест образа.

## 3. Образ доставки

- [ ] 3.1 Сборка musl-образа на Alpine-базе из артефактов ворот (без пересборки под другую libc);
      `readelf -l` каждого бинаря → `ld-musl-x86_64.so.1`.
- [ ] 3.2 Манифест образа: digest базовой системы, версии пакетов (`seatd-0.9.3-r1`,
      `pipewire-1.6.11-r0`, `pipewire-pulse-1.6.11-r0`, `wireplumber-0.5.19-r0`,
      `xdg-desktop-portal-1.22.1-r0`, `upower-1.91.0-r2`, `polkit-128-r0`, `weston-16.0.0-r0` —
      проверено `apk search` в контейнере ворот 21.11.2026), версии компонентов, sha256.
- [ ] 3.3 Проверка образа: в нём нет X11-библиотек, нет `journald`/`logind`, `openrc` + `seatd`
      поднимают сеанс (ADR-0023).
- [ ] 3.4 Smoke-сессия М2 прогоняется **в образе**, а не только в контейнере ворот.
- [ ] 3.5 Воспроизводимость: пересборка из того же тега и манифеста даёт тот же состав.
- [ ] 3.6 Формат пакетов внутри образа — по ADR; tar-снапшот как минимум; Live-ISO и инсталлятор
      зафиксированы как backlog после 1.0.
