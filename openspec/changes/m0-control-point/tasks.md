      напечатала «ГОТОВО» на несобранном дереве:
      (а) `meson setup build … . build` — лишний positional-аргумент, meson падает с
      `unrecognized arguments: build`;

      `meson test` прогнан, список упавших тестов записан.
- [ ] 2.3 Патчи, если понадобятся, — в `patches/efl-1.29.0/` с комментарием «почему нельзя иначе»;
