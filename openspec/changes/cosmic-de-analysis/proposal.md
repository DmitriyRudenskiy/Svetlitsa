## Why

COSMIC DE (System76) — единственный в экосистеме Linux рабочий стол, уже написанный на Rust:
30 пакетов `cosmic-epoch` поверх `libcosmic`/`iced`, плюс десятки мелких переиспользуемых крейтов
(`cosmic-config`, `freedesktop-desktop-entry`, `*-zbus`, `os-release`). Светлица пишет тот же по
объёму DE с нуля, но с другим GUI-стеком (EFL/Elementary, [ADR-0003](../../../docs/adr/ADR-0003.md))
и с MATE как контрактом. До того как закроется М1, нужно документированно ответить: что из чужого
Rust-опыта **переносимо**, что **добавляемо** как зависимость, а что **непереносимо** — иначе
«возьмём у COSMIC» будет приниматься по памяти и натыкаться на лицензии ([ADR-0002](../../../docs/adr/ADR-0002.md)).

Второй повод: `fsvm88/cosmic-overlay` — единственный поддерживаемый сторонний ebuild-оверлей,
который держит полный граф зависимостей COSMIC (136 ebuild, rust ≥ 1.93, LLVM 21–22, 19 общих
рантайм-зависимостей в `cosmic-common.eclass`). Это готовый, машиночитаемый ответ на вопрос «что
нужно для сборки DE», и он же — источник сверки для `docs/env-checklist.md`.

## What Changes

- Заводится **зеркало-анализаторий `idea/`** (в `.gitignore`, в git не попадает): репозитории
  pop-os клонируются **по одному**, `--depth 1 --single-branch --no-tags`, только подмножество,
  названное самим оверлеем, а не весь орг (300 репозиториев / 12.45 ГБ при 20 ГиБ свободных).
- Заводится **реестр разбора** `docs/analysis/cosmic/reestr.md`: одна строка на репозиторий —
  что это, лицензия, размер, вердикт `переносим` / `добавляем` / `не переносим` / `мимо`, и ссылка
  на наш крейт. Реестр — единственная форма вывода; отдельных отчётов на репозиторий не пишется.
- Разбор ведётся **поэтапно: один репозиторий → вердикт в реестр → коммит → следующий**.
  Промежуточных сводок и отчётов не делается; коммит = единица прогресса.
- Появляется **список пакетов для сборки DE** (`docs/analysis/cosmic/pakety.md`): тулчейн и
  рантайм-зависимости по данным eclass/ebuild, в две колонки — Gentoo-атом и Debian/Ubuntu-пакет,
  потому что среда ворот Светлицы — Ubuntu MATE 24.04 ([env-checklist](../../../docs/env-checklist.md)).
- Появляется **сравнение COSMIC ↔ Светлица** (`docs/analysis/cosmic/sravnenie.md`): 28 компонентов
  MATE из карты ТЗ 2 против космических эквивалентов, с явной пометкой уровня переносимости
  (контракт поведения / готовый крейт / содержимое / ничего).
- **Ничего не переносится в код и не добавляется в `Cargo.toml`** этой правкой: change закрывает
  вопрос «что можно», решение «берём» — отдельная задача с проверкой лицензии по ADR-0002.

## Capabilities

### New Capabilities
- `cosmic-reference-analysis`: порядок разбора внешнего Rust-DE как источника решений — что и в
  каком объёме зеркалится, как фиксируется вердикт по репозиторию, как считается шаг завершённым,
  и что именно обязан содержать список пакетов сборки и сравнение компонентов.

## Impact

- `idea/` — новый игнорируемый каталог-анализаторий (до ~2 ГБ); в git не входит.
- `docs/analysis/cosmic/` — три документа: `reestr.md`, `pakety.md`, `sravnenie.md`.
- `.gitignore` — добавляется `idea/`.
- `docs/journal.md` — запись раунда по итогам разбора (сколько репозиториев, сколько вердиктов
  «переносим»).
- Затрагиваемые решения (только как ссылка, без правки): ADR-0002 (лицензии), ADR-0003 (стек),
  ADR-0007 (композитор пост-1.0), ADR-0012/0014 (иконки).
- Код крейтов, `Cargo.toml`, `Cargo.lock`, ворота `xtask ci` — не меняются.
