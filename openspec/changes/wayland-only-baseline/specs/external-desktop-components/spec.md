## ADDED Requirements

### Requirement: Внешний компонент получает вердикт до строчки кода

Компонент, не входящий в 43 репозитория MATE (раздел 2 ТЗ), SHALL получить вердикт —
`портируем` / `берём механику` / `потребляем по протоколу` / `не портируется` — с фактами о
первоисточнике (`HEAD`, лицензия, объём, активность) до того, как под него появится крейт или
задача. Вердикт SHALL записываться в `docs/analysis/externals/` и в `TASK.md` (9.29 либо новая
строка карты 2).

#### Scenario: Факты, а не впечатление

- **WHEN** вердикт выносится
- **THEN** в нём указаны `HEAD` и дата коммита, лицензия по файлам репозитория, объём кода и признак
  жизни проекта
- **AND** лицензия взята из файлов репозитория, а не из описания на хостинге

#### Scenario: Портирование чужой кода требует отдельного решения

- **WHEN** вердикт — `портируем`
- **THEN** открыт ADR с разбором лицензии первоисточника и объёмом переносимых строк
- **AND** без ADR задача на портирование не заводится

### Requirement: gxneur не портируется, его забота делится между композитором и «Букварём»

`RussianFedora/gxneur` SHALL быть помечен как не портируемый, а забота «переключение и индикация
раскладки» SHALL быть закрыта другими компонентами.

#### Scenario: Основание вердикта

- **WHEN** читается вердикт по `gxneur`
- **THEN** в нём записано, что репозиторий — пакетная обёртка (3 866 байт рабочего дерева, `HEAD` `e1f7229`
  2012-08-30, файла `LICENSE` нет, `GPLv2` указан только в `gxneur.spec`), а сам аплет — GTK-обёртка
  над X Neural Switcher, то есть X-события и XKB состояния процесса
- **AND** в Wayland--only сеансе клиентского способа наблюдать смену раскладки нет

#### Scenario: Индикатор читает состояние у композитора

- **WHEN** лавка показывает раскладку активного окна
- **THEN** состояние получено по собственному протоколу сеанса от композитора
- **AND** у «Букваря» есть модель раскладок (список, опции, порядок переключения) без `xkbcomp`

### Requirement: Менеджер буфера обмена — новый компонент с явной границей приватности

Менеджер буфера обмена SHALL быть собственным компонентом «Светлицы» по образцу `parcellite`, а не
его портом: 43 репозитория MATE менеджера буфера не содержат. Компонент SHALL работать там, где
работает сеанс, то есть через `zwlr-data-control`, а не через X-владение selection.

#### Scenario: Образец, а не код

- **WHEN** компонент проектируется
- **THEN** из `parcellite` (`GPL-3.0`, `HEAD` `4a0eafd` 2025-12-16, 7 300 строк C) взяты модель
  истории, режимы «буфер/primary», выгрузка по горячей клавише и поведение меню
- **AND** его `keybinder.c` (Xlib, `XGrabKey`) не переносится: горячая клавиша регистрируется
  композитором

#### Scenario: Секреты в историю не пишутся

- **WHEN** содержимое буфера помечено источником как конфиденциальное либо приложение запретило
  сохранение (`text/x-kde-ignore`-семантика, отказ от `zwlr-data-control`-источника)
- **THEN** запись в историю не попадает
- **AND** история шифруется/ограничивается правами пользователя и очищается по требованию

#### Scenario: Композитор обязателен

- **WHEN** сеанс построен на композиторе без `zwlr-data-control`
- **THEN** компонент не запускается и честно сообщает причину, а не молча теряет историю

### Requirement: NetworkManager потребляется по D-Bus, демон не портируется

`NetworkManager` SHALL использоваться как внешняя служба сеанса на тех же правах, что
`logind`/`UPower`: через D-Bus, без портирования и без линковки `libnm`.

#### Scenario: Граница ограничения 12.15

- **WHEN** описываются сетевые возможности 1.0
- **THEN** просмотр устройств, список сетей, подключение/отключение и статус — в объёме, а
  редактор соединений (IP, маршруты, VPN, 802.1X) — вне 1.0
- **AND** для секрета сети есть секрет-агент сеанса, а не запрос через терминал

#### Scenario: Основание вердикта

- **WHEN** читается вердикт по `NetworkManager`
- **THEN** в нём записано: `GPL-2.0+` (демон) и `LGPL-2.1+` (`libnm`), `HEAD` `ea60638`
  2026-11-20, 665 555 строк C, проект активен
- **AND** указано, что клиент пишется на `zbus`, а не через `libnm`, чтобы не тянуть GLib-стек в
  крейты сеанса

#### Scenario: Секрет-агент — собственный клиент сеанса

- **WHEN** сеть требует пароль (PSK, 802.1X) и у сеанса нет сохранённого секрета
- **THEN** сеанс сам реализует `org.freedesktop.NetworkManager.SecretAgent` и запрашивает секрет
  в окне, принадлежащем «Светлице»
- **AND** polkit-агент не является зависимостью сеанса и ни один DoD от него не зависит

#### Scenario: Секреты не растекются по конфигу

- **WHEN** секрет сохранён для повторного подключения
- **THEN** он лежит в каталоге сеанса с правами владельца (каталог `0700`, файл `0600`)
- **AND** он не попадает в `svetlitsa-config`, в историю буфера обмена и в журналы

### Requirement: conky не портируется, его Wayland-механика идёт в образец

`conky` SHALL быть помечен как не портируемый; его назначение — быть образцом «настенного» окна на
Wayland. Включение настенного монитора в контракт SHALL быть отдельным решением владельца, потому
что в 43 репозитория MATE такого приложения нет.

#### Scenario: Механика зафиксирована

- **WHEN** описывается настенный виджет (часы, монитор на обоях)
- **THEN** ссылка идёт на Wayland-сборку `conky` (`GPL`/`BSD`, `HEAD` `ddbc7ac` 2026-11-20,
  51 495 строк C++ в `src/`, `BUILD_WAYLAND` по умолчанию выключён): `xdg-shell` +
  `wlr-layer-shell`, слои `background`/`overlay`, разделение кликабельности
- **AND** код `conky` (включая Lua-движок) не переносится

#### Scenario: Решение о объёме принимает владелец

- **WHEN** встает вопрос, входит ли настенный монитор в 1.0
- **THEN** в задачах стоит `post-MVP` и ссылка на ADR, которого ещё нет
- **AND** ни один майлстоун не содержит этого компонента молча

### Requirement: Лицензии внешних компонентов не въезжают в проект бесплатно

Любое использование внешнего компонента SHALL быть совместимо с лицензионной моделью «Светлицы» на
момент, когда оно становится зависимостью, а не на момент вердикта.

#### Scenario: Модель вместо кода

- **WHEN** у компонента лицензия, несовместимая с планами проекта (`GPL-3.0` у `parcellite` при
  намерении встроить код в `LGPL`-крейт)
- **THEN** переносится только модель поведения, а заимствование кода требует ADR
- **AND** в `docs/licenses.csv` появляется запись только когда появляется зависимость
