Итерации (а)–(г) заданы ADR-0019 и обязательны по порядку. Каждая позиция парити-листа закрывается
по ТЗ 5 и 6.9; «собрано» не является прогрессом, прогресс — закрытая позиция плюс сценарий.

## 1. Итерация (а): окно + фокус + привязка — первая метрика проекта

- [ ] 1.1 `starshina`: каркас на smithay, запуск под DRM/KMS и под headless-головой (`weston`
      как родитель для разработки), вывод списка подключённых устройств через слой сидов (`seatd`).
- [ ] 1.2 `xdg_shell`: клиент подключается, окно появляется, фокус по клику и по привязке.
- [ ] 1.3 Глобальные привязки: минимальный набор (закрыть окно, сфокусить следующее).
- [ ] 1.4 **Замер:** число итераций и прогонов `xtask ci` на «окно + фокус + привязку» — в журнал;
      пересчёт оценки XL в `docs/roadmap.md`.
- [ ] 1.5 Парити-лист `starshina` по зеркалу `marco`: перечень позиций, вердикты владельца (Q47–Q49).

## 2. Итерация (б): список окон + слои

- [ ] 2.1 Перемещение/изменение размера, минимизация/восстановление, закрытие по `xdg_toplevel.close`.
- [ ] 2.2 Рабочие столы: переключение, привязка окон к столу.
- [ ] 2.3 Alt+Tab: окно-переключатель, порядок, отмена по Esc.
- [ ] 2.4 `wlr-layer-shell`: панель и обои ложатся под окна; проверка снимком.
- [ ] 2.5 `ext-idle-notify-v1`: событие простоя (потребитель — `stavni`, М4).
- [ ] 2.6 Собственный захват экрана: кадр окна и кадра экрана (потребители — smoke, `dagerotip` М3).

## 3. Итерация (в): протоколы сеанса

- [ ] 3.1 `org.svetlitsa.Session`: список окон, заголовки, состояния, активный стол, активная
      раскладка, запросы завершения/блокировки; XML + README крейта.
- [ ] 3.2 Wayland-протокол там, где состояние живёт у композитора (выводы, раскладка, слой).
- [ ] 3.3 `svetlitsa-platform`: граница сидов (`seatd` + `dummy`), реализации `logind` нет
      (задача 5.1 `musl-only-libc`).
- [ ] 3.4 Индикатор раскладки читает состояние у композитора (замена X Neural Switcher, ТЗ 9.31).

## 4. Итерация (г): сервисы сеанса

- [ ] 4.1 `klyuchnik`: автозапуск XDG, экран завершения, `org.svetlitsa.Session`, shim
      `org.gnome.SessionManager`, `Lock`/`Unlock` + inhibitor через слой сидов (задача 5.2
      `musl-only-libc`).
- [ ] 4.2 `domovoy`: применение раскладок через `bukvar` на стороне композитора, фон через `izba`,
      медиа-клавиши (привязки композитора + PipeWire, ADR-0022).
- [ ] 4.3 `lavka`: панель на `wlr-layer-shell`, лаунчеры, список окон по протоколу сеанса,
      трей SNI, часы на таблицах М1, реестр плагинов в-процессе.
- [ ] 4.4 `vestnik`: `org.freedesktop.Notifications`, пузыри на `svetlitsa-ui`, приоритеты,
      do-not-disturb.
- [ ] 4.5 `svetlitsa-demo`: контракт ТЗ 10.2 — `--windows N`, `--tray`, app-id и заголовки.
- [ ] 4.6 `svetlitsa-input`: инъекция `virtual-keyboard-unstable-v1` + мышь, вызов только из
      `xtask smoke`.

## 5. Smoke-сессия (DoD М2)

- [ ] 5.1 `xtask smoke session`: два демо-окна + панель + вестник под `starshina`; шаги —
      запуск, фокус, привязка, уведомление, трей, завершение по D-Bus.
- [ ] 5.2 Ожидания — поллинг по протоколу сеанса; ни одного `sleep`; снимок при падении шага.
- [ ] 5.3 Проверка отсутствия зависших процессов после завершения сеанса.
- [ ] 5.4 Снимки 1024×768 и 1920×1080 в `artifacts/session/`, «тема не серая» механически.
- [ ] 5.5 Прогон в контейнере ворот; отчёт содержит digest образа, `rustc --version`, путь рендера.
