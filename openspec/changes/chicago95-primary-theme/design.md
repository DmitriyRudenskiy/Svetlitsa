# Design: chicago95-primary-theme

## Context

Визуальная система «Светлицы» сегодня — тема «Лубок» (ТЗ 7.3): EDC-тема Elementary, палитры
«Гжель»/«Хохлома»/«Мезень», декор «Наличники», закрытые списки виджетов и иконок (ADR-0012),
ворота 10.3 красят «серую тему» как брак. Каталог `themes/` пуст (`.gitkeep`): кода темы нет,
есть только контракт — это редкий случай, когда смена художественного направления дешевле до кода,
чем после.

Chicago95 — GTK2/GTK3/GTK4-тема, курсоры, иконки, шрифты-битмапы и звуки Windows 95 для Xfce/KDE.
«Светлица» — Wayland + EFL/Edje; GTK-темы не переносятся по определению (ТЗ 12.4). Поэтому
«сделать Chicago95 основной темой» технически означает **перенос визуального языка** (геометрия,
палитра, метрики, ритм отступов) в EDC-тему, а не установку чужого CSS.

Ограничения среды: musl/Alpine, EFL 1.29, ворота в Docker; `xtask licenses` сверяет лицензии по
upstream (ADR-0002); `xtask icons --check` сверяет закрытый список freedesktop-имён.

## Goals / Non-Goals

**Goals:**
- Тема «Чикаго» (Win95) — тема по умолчанию во всех компонентах с М1; «Лубок» — выбираемая
  альтернатива, не брак и не удалённое направление.
- Машинночитаемые токены: цвета, метрики, шрифтовая пара — единственный источник, из которого
  живут и EDC, и ворота 10.3, и скриншотные эталоны.
- Чистые лицензии: в репозитории нет ни одного файла из Chicago95 и ни одного ассета,
  воспроизводящего проприетарные продукты Microsoft.
- Канон обновлён без «второй правды»: ADR-0024 + правка ТЗ 7.3/GLOSSARY, а не ветвление
  формулировок.

**Non-Goals:**
- Vendoring ассетов Chicago95 (CSS, PNG, курсоры, звуки, битмап-шрифты) — у репозитория нет LICENSE.
- Звуковая тема Win95 и шрифт MS Sans Serif — остаются «Колокольчики» и PT Sans/PT Serif с фолбэком.
- Портирование GTK-тем, поддержка «Plus!»-конвертера тем Windows, HiDPI-варианты — после М3.
- Удаление «Лубка», «Гжели», «Хохломы», «Наличников», маскота «Конёк» и русской системы имён.

## Decisions

### D1. Переносим язык, а не файлы (EDC, не GTK CSS)
Тема «Чикаго» — EDC-макет Elementary в `themes/chicago/`, той же архитектуры, что планировалась
для «Лубка» (ADR-0004 про Edje-макеты сохраняется). Альтернатива «сконвертировать GTK CSS в EDC»
отвергнута: CSS-модель виджетов Chicago95 завязана на GTK-селекторы и pixbuf-движок, конвертер
оказался бы вторым движком рендеринга.

### D2. Токены темы — один источник
`themes/chicago/tokens.toml`: палитра (face `#C0C0C0`, highlight/shadow для фасок, `#FFFFFF`/`#DFDFDF`
поля, `#000080`→`#1080B0` заголовок, `#008080` обои, `#000000`/`#FFFFFF` текст, `#000080` выделение),
метрики (фаска 2 px, панель 28 px, иконки 16/32/48, базовый шаг 4 px), шрифт. EDC генерируется из
токенов (или читает их как параметры), ворота 10.3 и парити-лист сверяются с тем же файлом
(принцип «копия у списка одна», ADR-0014). Альтернатива — цвета прямо в EDC — отвергнута: ворота
останутся «серой темой» на глаз.

### D3. Палитры и имена
Новая система палитр темы по умолчанию: **«Чикаго»** (светлая, default), **«Графит»** (тёмная:
лицо `#3A3A3A`, та же фаска), **«Мезень»** без изменений (доступность). «Гжель»/«Хохлома» остаются
выбираемыми. Имена — русские, в транслитерации бинарей не нуждаются (это не компонент). Это
**отменяет** запрет ADR-0012 на переименование палитр — только в части «названия из ТЗ 7.3
неизменны»; запрет второй системы имён (ТЗ 6.6/7.2) сохраняется: имена палитр одна система,
англоязычных алиасов нет. Альтернатива «назвать Win95-палитру Гжелью» отвергнута: слово врёт
пользователю.

### D4. Иконки — своего производства, список не меняется
Закрытый список имён (freedesktop, `xtask icons`) остаётся как есть; меняется стиль рисунка:
сплошные заливки, чёрный контур 1 px, сетка 16 px, без сглаживания «под пиксель». Рисуются свои
PNG/SVG; каталог Chicago95/Icons не используется (нет лицензии + иконки воспроизводят Microsoft).
Порядок: пиктограммы М2-виджетов из списка `svetlitsa-ui` — до заморозки токенов М3.

### D5. Ворота 10.3 переписываются, а не отключаются
Критерий «серая тема — брак» заменяется на «UI обязан совпадать с токенами выбранной темы»:
пустой/дефолтный Elementary без темы по-прежнему красные, но `#C0C0C0` из токена — законный цвет.
SSIM-эталоны (ТЗ 1016 строка) перетираются один раз, после заморозки токенов.

### D6. Канон: ADR-0024 до кода
Смена направления фиксируется ADR-0024 («Тема по умолчанию — „Чикаго" (Win95); „Лубок" —
альтернатива»), отменяющим часть ADR-0012 и переписывающим ТЗ 7.3, GLOSSARY, roadmap. Раунд
журнала и голова canon.toml — по обычной процедуре. Без ADR правка считается самовольной сменой
контракта.

## Risks / Trade-offs

- [Chicago95 без LICENSE → любое копирование ассетов нарушает авторское право] → правило «только
  визуальный язык»; в `xtask licenses` — запрет-лист источников (grassmunk/Chicago95); ассеты —
  собственные, OFL/CC0/свои.
- [Trade dress Microsoft: «слишком похоже»] → решение владельца фиксируется в ADR-0024; мы не
  используем логотипы/звуки/шрифты MS, только геометрию и цвета — цвета и форма виджетов не
  охраняются, но степень сходства — юридический риск владельца, не агента.
- [Смена направления обесценивает «народную» эстетику ТЗ 7.2/7.3] → «Лубок» сохраняется как
  альтернативная тема, маскот и имена не трогаются; обратное переключение — одна настройка темы.
- [Ворота 10.3 после переписывания пропустят «серую» регрессию] → критерий привязан к токенам,
  а не к «не-серый»: отсутствие темы по-прежнему красный, отсутствие токенов — красный.
- [Мелкий растр Win95 конфликтует с HiDPI и доступностью] → «Мезень» не меняется; масштабирование
  фаски кратно пикселю, крупный шрифт — параметр темы.

## Migration Plan

1. ADR-0024 + правки ТЗ 7.3/GLOSSARY/roadmap (до кода темы).
2. `themes/chicago/tokens.toml` + генерация/параметризация EDC, `svetlitsa-ui` грузит «Чикаго».
3. Иконки М2-набора в новом стиле; `xtask icons --check` зелёный на прежнем списке имён.
4. Перетирка скриншотных эталонов, зелёные ворота в Docker-среде.
Откат: тема выбираемая — откат равен смене темы по умолчанию на «Гжель» + отзыв ADR-0024.

## Open Questions

- Имена тёмной палитры («Графит» предложено) и самого семейства («Чикаго» vs «Окно») — за владельцем
  до заморозки токенов.
- Курсоры: свой набор в стиле Win95 или системный default до М3?
- Обои «Пейзажи»: остаются народными или заводятся «как рабочий стол 95» (бирюза + окно)?
