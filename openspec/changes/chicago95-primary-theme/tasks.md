Порядок фиксирован зависимостью «канон → токены → тема → ворота»: ни одной строки в `themes/chicago/`
до принятого ADR-0024 (спека, требование «Смена направления зафиксирована в каноне»). Задачи 1.x —
документы, 2.x–5.x — первая настоящая тема проекта (каталог `themes/` сегодня пуст).

## 1. Канон: ADR-0024 и правки контракта

- [ ] 1.1 `docs/adr/ADR-0024.md`: тема по умолчанию — «Чикаго» (Win95), «Лубок» — альтернатива;
      отмена части ADR-0012 (имена палитр), сохранение закрытых списков и запрета второй системы
      имён; фиксация решения владельца о степени сходства с trade dress Microsoft.
- [ ] 1.2 Правка ТЗ 7.3: абзац «Тема „Чикаго"» (палитры «Чикаго»/«Графит»/«Мезень», «Гжель»/«Хохлома»
      — альтернативы), формулировка ворот 10.3 «соответствие токенам» вместо «не-серости».
- [ ] 1.3 Правка GLOSSARY: статья «Тема „Лубок"» (альтернативная), новые статьи «Тема „Чикаго"»,
      «Графит»; проверка, что ТЗ 6.6/7.2 (одна система имён) не нарушены.
- [ ] 1.4 `docs/roadmap.md`: строка темы — «Чикаго» по умолчанию, заморозка токенов до М3;
      запись раунда в `docs/journal.md`, тег и голова `canon.toml` (по процедуре, теги/пуш — владелец).
- [ ] 1.5 Имена палитр («Чикаго»/«Графит») утверждены владельцем (open question design.md) —
      до 2.1.

## 2. Токены и запрет-лист лицензий

- [ ] 2.1 `themes/chicago/tokens.toml`: палитра (face/highlight/shadow/заголовок/обои/выделение),
      метрики (фаска 2 px, панель 28 px, иконки 16/32/48, шаг 4 px), шрифт PT Sans с фолбэком DejaVu.
- [ ] 2.2 Парсер/схемa токенов в `xtask`: валидация формата, вывод «текущие токены» для ворот

      звуки Win95); красный на любом файле-копии (сверка по хешам контрольного списка upstream).

## 3. EDC-тема «Чикаго»

- [ ] 3.1 Каркас `themes/chicago/`: структура EDC-макета Elementary (вместо планировавшегося
      «Лубка»), подключение к загрузке `svetlitsa-ui` (тема по умолчанию из `svetlitsa-config`).
- [ ] 3.2 Базовые примитивы фасок: raised/sunken 2 px, поле ввода (sunken-кант), кнопка
      (normal/pressed/insensitive) — по спеке, без скруглений/теней.
- [ ] 3.3 Виджеты закрытого списка М2 (`docs/parity/svetlitsa-ui.md`): меню, диалог, список,
      тулбар, StatusStrip — состояния фокуса и неактивности.
- [ ] 3.4 Палитра «Графит» как второй набор токенов того же макета; проверка переключения
      «Чикаго»/«Графит»/«Гжель» одной настройкой.
- [ ] 3.5 «Мезень»: сверка, что контрастная палитра и отключение анимаций работают поверх новой
      геометрии без изменений своего контракта.
