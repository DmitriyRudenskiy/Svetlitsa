# Proposal: chicago95-primary-theme

## Why

Владелец проекта сменил художественное направление: основной темой графического дизайна становится
Windows 95 — визуальный язык репозитория [grassmunk/Chicago95](https://github.com/grassmunk/chicago95)
(фаски-рамки, серая «пластмасса» `#C0C0C0`, синий заголовок, бирюзовый рабочий стол). Текущий канон
(ТЗ 7.3, ADR-0012, GLOSSARY) фиксирует обратной порядок: народно-художественная тема «Лубок»
(Гжель/Хохлома/Мезень) — единственная визуальная система, а «серая тема по умолчанию считается браком».
Значит направление — не правка CSS, а смена контракта: без ADR и правки ТЗ 7.3 ворота 10.3
(«серая тема — брак») начнут воевать с новым требованием.

## What Changes

- **BREAKING** Тема Windows 95 («Чикаго») становится темой по умолчанию: новый ADR-0024 отменяет
  часть ADR-0012 («названия палитр неизменны») и переписывает ТЗ 7.3 — «Лубок» из «единственной
  визуальной системы» становится «альтернативной палитрой», а не браком и не удалением.
- Визуальный язык Chicago95 переносится **языком EDC, а не файлами репозитория**: геометрия фасок
  (raised/sunken 2 px), палитра (`#C0C0C0` face, `#000080`/`#1080B0` заголовок, `#008080` обои,
  `#FFFFFF`/`#000000` текст), метрики (панель 28 px, кнопка 11 px, иконки 16/32/48), шрифт-пара с
  заменой MS Sans Serif на свободный аналог. **Ни один ассет Chicago95 в репозиторий не vendорится**
  (см. Impact: у репозитория нет файла LICENSE — GitHub API `license: null`; плюс ассеты сами
  воспроизводят проприетарные продукты Microsoft: шрифты, звуки, иконки).
- Палитры: светлая «Чикаго» (default), тёмная «Графит» (Win95-геометрия, тёмное лицо), контрастная
  «Мезень» остаётся без изменений (доступность важнее направления). Народные палитры «Гжель»/«Хохлома»
  сохраняются как выбираемые альтернативы; закрытый список виджетов ADR-0012 распространяется на
  «Чикаго» в первую очередь.
- Декор окон «Наличники» получает Win95-вариант (заголовок с градиентом, кнопки `_ □ ×`); народный
  «Наличники» остаётся альтернативой. Звуковая тема «Колокольчики» **не меняется**: звуки Win95 —
  объект прав Microsoft, в vendoring и синтез-«один-в-один» эта задача не входит.
- Маскот «Конёк», русская система имён компонентов и D-Bus-имена не меняются: меняется только
  слой «как выглядит», а не «как называется».

## Capabilities

### New Capabilities

- `chicago95-theme`: визуальная система «Чикаго» — токены палитр и метрик, правила EDC-реализации
  Win95-геометрии, закрытый список виджетов М2 в новом стиле, иконки в стиле Win95 (собственного
  производства, freedesktop-имена), декор окон, критерии ворот 10.3 для новой темы по умолчанию.

### Modified Capabilities

Спеков в `openspec/specs/` ещё нет (синхронизация не проводилась); требования темы сейчас живут
в дельтах открытых change'ей:

- `ui-toolkit-surface` (change `m1-toolkit-foundation`) — «тема „Лубок" через Edje» становится
  «тема по умолчанию из токенов `chicago95-theme`, «Лубок» — вторая палитра»: дельта не заводится
  в этот change, фиксация идёт через правку ТЗ 7.3 и ADR-0024, а change `m1` при применении
  берёт тему по умолчанию из нового контракта.
- `wayland-compositor` (change `m2-session-frame`) — декор окон: вариант «Наличники»/Win95 выбирается
  темой, по умолчанию Win95.

## Impact

- **Канон:** новый ADR-0024 (смена направления, отменяет часть ADR-0012); правка ТЗ 7.3,
  GLOSSARY (статьи «Тема „Лубок"», палитры), `docs/roadmap.md` (строка темы), раунд журнала.
- **Код:** `themes/` (пуст — становится деревом «Чикаго»: EDC, палитры, метрики), `svetlitsa-ui`
  (загрузка темы по умолчанию), `xtask icons` (закрытый список имён не меняется — имена freedesktop,
  стиль рисунка новый), ворота 10.3 (эталон «не серая тема» переопределяется: серость `#C0C0C0`
  по требованию — не брак; критерий меняется на «соответствие токенам темы»).
- **Лицензии (красный флаг, решается до первой строки ассетов):** в `grassmunk/Chicago95`
  **отсутствует LICENSE** — по умолчанию «все права защищены», копирование CSS/PNG/звуков/шрифтов
  недопустимо; `xtask licenses` это поймает. Переносим только **визуальный язык** (геометрия,
  цвета — не объект авторского права), ассеты рисуем сами. Отдельный риск — trade dress Microsoft:
  решение о степени сходства принимает владелец, ADR обязан это зафиксировать.
- **Не входит:** звуки Win95, шрифт MS Sans Serif, иконки из Chicago95, портирование GTK CSS
  (ТЗ 12.4: GTK-темы не переносятся), удаление «Лубка».
